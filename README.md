# 광물에서 명전까지

이터널 리턴 소재의 한국어 싱글플레이 선수 육성 시뮬레이션 MVP입니다.

## 실행

```bash
npm install
npm run dev
```

검증: `npm test`, 배포 빌드: `npm run build`

현재 구현: 단계별 선수 생성, 역할군 내 주력 실험체 랜덤 배정, 12주 단위 시즌 진행, 랭크·RP, 팀/대회 커리어, 장비, 명예의 전당, 브라우저 자동 저장.
