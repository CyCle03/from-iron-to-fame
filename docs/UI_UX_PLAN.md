# UI/UX 개선 계획

> 기준일: 2026-10-23. 2026-11-16 정적 코드 대조로 현재 상태를 교정했다. 브라우저·모바일 실기기 검증은 별도다. 기능 로직과 저장 호환성을 유지하면서 화면 탐색과 의사결정 속도를 개선한다.

## 1차 — 디자인 기반·탐색·대시보드 (구현됨)

- 색상, 간격, 모서리, 포커스 링을 CSS 디자인 토큰으로 정의했다.
- 버튼 비활성 상태와 키보드 포커스를 공통 스타일로 통일했다.
- 데스크톱에는 가로 탐색, 모바일에는 안전 영역을 고려한 하단 고정 탐색을 적용했다.
- 장비·게임 안내·저장 관리는 모바일 더보기 메뉴에서 접근한다.
- 대시보드의 다음 목표는 현재 RP·인지도·팀·우승 상태에서 부족한 조건을 계산해 표시한다.
- `prefers-reduced-motion` 사용자의 애니메이션 최소화 설정을 지원한다.
- 신규 선수 생성에서 배경과 역할군을 각각 무작위로 다시 선택할 수 있다.

## 2차 — 시즌 선택과 결과 비교 (구현됨)

- 시즌 계획 카드에 예상 랭크 경기 수, 정성적 부담(`load`), 주요 성장 방향(`focus`)을 표시한다. 수치화된 피로 예측은 아직 없다.
- 0단계(지난 계획 유지) 화면에서 12주 진행을 안내하고, 2단계 확인 화면은 공식 대회 자동 진행 여부와 예상치를 보여 준다. 확인 화면 자체에 12주 범위 문구는 아직 없다.
- 시즌 종료 후 랭크·RP 변동, 인지도 획득, 경기 수, 평균 순위·우승·TOP 3 비율과 공식 일정 개수를 비교한다. 최고 순위 비교는 아직 없다.
- 예상치는 실제 능력치·메타·피로와 경기 결과에 따라 달라질 수 있음을 명시한다.

## 3차 — 팀·계약 통합 (구현됨)

- 로스터와 계약·이적 패널을 별도 팀 허브로 통합했다.
- 팀명, 리그, 계약 기간, 급여, 주전 평균 폼, 팀워크와 제안 수를 상단에 요약한다.
- 후보 교체 전에 교체되는 주전, 단순 전력 변화와 팀워크 비용을 표시한다.
- 현재 계약 대비 제안 급여 차이와 리그 변화를 같은 카드에서 비교한다.

## 4차 — 저장·피드백·접근성 (구현됨)

- `커리어 관리` 모달과 커리어 기록 패널 모두 은퇴를 2단계로 확인한다. 취소하면 현역 상태와 기록을 그대로 유지한다.
- 은퇴 후 기록 화면에서도 커리어 관리에 접근해 백업하거나 데이터를 삭제하고 새 커리어를 시작할 수 있다.
- 가져온 파일을 적용하기 전에 선수, 시즌, 랭크, 주 실험체, 팀과 마이그레이션 후 저장 버전(현재 7)을 미리 보여 준다. 원본 파일 버전과 현재 커리어 대비 변경 요약(diff)은 표시하지 않는다.
- 브라우저 경고창 대신 성공·오류 토스트와 2단계 초기화 확인을 사용한다.
- 저장 관리·시즌 결산·성취 결과 모달은 `useModalDialog`로 초기 포커스, Tab 순환, Escape 닫기, 포커스 복귀와 배경 스크롤 잠금을 공유한다.
- 저장 관리 모달이 열린 동안 배경 스크롤을 차단하며, 같은 파일도 연속으로 다시 선택할 수 있다.
- 계약·이적·훈련·장비·대회 등 게임 상태 변경 결과를 공통 토스트 시스템으로 알린다.
- 랭크 경기와 대회 라운드 표는 모바일에서 각 열 이름을 보존한 카드 목록으로 전환한다.
- 저장 미리보기·적용, 삭제·은퇴 취소/확인, 시즌 결산 키보드 순환과 Escape 복귀를 DOM 테스트로 검증한다.

## 5차 — 주요 성취 결과 연출 (구현, 검증 범위는 아래 참조)

- 시즌 전후 공식 대회 이력의 차이로 KeG·마스터즈·KEL 등의 결과와 우승을 표시한다. 순위·CP, 전체 일정 인지도 증가 합계와 다음 목표를 제공하며 우승은 트로피와 대회명으로 구별한다.
- 수상 기록의 차이로 MVP·시즌 베스트와 스타즈·히어로즈·아너스를 `대회 결과 → 개인 수상 → 커리어 이정표` 순서로 표시한다.
- 기록은 결과 확인 전에 저장한다. 연출은 현재 세션 상태로만 유지하므로 새로고침·저장 가져오기는 과거 결과를 재생하지 않는다. 모두 건너뛰기와 Escape를 지원한다.
- 반복 수상은 상세 설명을 생략하고, 모션 감소 시 기존 전환 애니메이션을 제거한다.
- `TournamentView`는 마지막 라운드의 메타·숙련도·로스터 전력 보정값을 표시한다.
- 실제 Ego Chromium으로 다음을 확인했다: 1920×956 신규 커리어 → KeG 지역/전국 우승 결과 → 시즌 결산 → Escape → 새로고침 후 저장 유지·중복 연출 없음. 마스터즈 결과 큐와 대회 보정값도 확인했다. 390×844·모션 감소 환경에서 성취 모달 가로 넘침 없음(문서 폭 390px), 닫기 44px을 확인했다. 기록 패널 은퇴 확인과 취소를 조작했다. 모든 수상 유형의 실제 커리어 화면 및 실기기 스크린리더 검증은 별도다.

## 다음 개선 후보

- 토스트가 짧은 시간에 여러 개 발생할 때 최근 알림 기록을 펼쳐 보는 알림 센터
- 실제 모바일 뷰포트 기반 시각 회귀 테스트와 명암 대비 자동 검사
- 표 카드의 정렬·필터 기능과 긴 커리어 기록 가상 스크롤

## 검증 기준

- 모바일에서 핵심 화면을 두 번 이내의 조작으로 연다.
- 비활성 동작은 부족 조건을 텍스트로 설명한다.
- 모든 대화형 요소는 키보드 포커스가 보이고 최소 44px 터치 영역을 확보한다. 시즌 결산·성취 모달 닫기 버튼도 44×44px로 맞췄다.
- `npm run check`가 포맷, 린트, 타입, 테스트와 빌드를 모두 통과한다. 현재 통과 여부는 별도 검증 기록을 따른다.
