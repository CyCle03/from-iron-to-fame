# UI/UX 개선 계획

> 기준일: 2026-10-22. 기능 로직과 저장 호환성을 유지하면서 화면 탐색과 의사결정 속도를 개선한다.

## 1차 — 디자인 기반·탐색·대시보드 (구현됨)

- 색상, 간격, 모서리, 포커스 링을 CSS 디자인 토큰으로 정의했다.
- 버튼 비활성 상태와 키보드 포커스를 공통 스타일로 통일했다.
- 데스크톱에는 가로 탐색, 모바일에는 안전 영역을 고려한 하단 고정 탐색을 적용했다.
- 장비·게임 안내·저장 관리는 모바일 더보기 메뉴에서 접근한다.
- 대시보드의 다음 목표는 현재 RP·명성·팀·우승 상태에서 부족한 조건을 계산해 표시한다.
- `prefers-reduced-motion` 사용자의 애니메이션 최소화 설정을 지원한다.
- 신규 선수 생성에서 배경과 역할군을 각각 무작위로 다시 선택할 수 있다.

## 2차 — 시즌 선택과 결과 비교 (구현됨)

- 시즌 계획 카드에 예상 경기 수, 피로, 주요 성장 능력치를 표시한다.
- 확인 화면에서 공식 대회 자동 진행 여부와 12주 진행 범위를 안내한다.
- 시즌 종료 후 랭크, RP, 명성, 경기 수, 최고 순위와 공식 일정 변화를 비교한다.
- 예상치는 실제 능력치·메타·피로와 경기 결과에 따라 달라질 수 있음을 명시한다.

## 3차 — 팀·계약 통합 (구현됨)

- 로스터와 계약·이적 패널을 별도 팀 허브로 통합했다.
- 팀명, 리그, 계약 기간, 급여, 주전 평균 폼, 팀워크와 제안 수를 상단에 요약한다.
- 후보 교체 전에 교체되는 주전, 단순 전력 변화와 팀워크 비용을 표시한다.
- 현재 계약 대비 제안 급여 차이와 리그 변화를 같은 카드에서 비교한다.

## 4차 — 저장·피드백·접근성 (부분 구현)

- 저장 관리와 새 커리어 확인을 하나의 모달로 통합했다.
- 가져온 파일을 적용하기 전에 선수, 시즌, 랭크, 주 실험체, 팀과 저장 버전을 미리 보여 준다.
- 브라우저 경고창 대신 성공·오류 토스트와 2단계 초기화 확인을 사용한다.
- 모달을 열면 닫기 버튼에 포커스를 두고 `Escape`로 닫을 수 있으며, 같은 파일도 연속으로 다시 선택할 수 있다.
- 다음 단계에서는 주요 게임 행동의 피드백도 공통 토스트로 통합하고, 표의 모바일 카드 대체 화면과 모달 포커스 순환을 검증한다.

## 검증 기준

- 모바일에서 핵심 화면을 두 번 이내의 조작으로 연다.
- 비활성 동작은 부족 조건을 텍스트로 설명한다.
- 모든 대화형 요소는 키보드 포커스가 보이고 최소 44px 터치 영역을 확보한다.
- `npm run check`가 포맷, 린트, 타입, 테스트와 빌드를 모두 통과한다.
