# 구현 로드맵

> 기준일: 2026-10-22. 현재 코드와 테스트를 기준으로 작성하며, 세부 규칙은 [GAME_DESIGN.md](GAME_DESIGN.md), [ESPORTS_RULES.md](ESPORTS_RULES.md), [RANK_AND_CAREER_SYSTEMS.md](RANK_AND_CAREER_SYSTEMS.md)를 따른다.

## 현재 기준선

이미 구현된 범위는 선수 생성, 12주 시즌 운영, 랭크·성장·장비, 3인 스쿼드와 KEL 4인 로스터, 지역 컵→마스터즈→KEL 커리어, 대회 픽 제한, 시즌 결산, 명예의 전당, 브라우저 자동 저장이다.

다음 개발의 목표는 기능 수를 늘리는 것보다 **대회 한 시즌을 끝까지 완주하고, 선수의 선택이 다음 시즌과 커리어에 남게 만드는 것**이다.

## 단계별 계획

### 1. 시즌 경쟁 구조 완성 — 구현됨

- 48개 AI 팀과 팀별 전력·폼·로스터를 생성한다.
- 마스터즈 3개 페이즈의 전체 순위와 누적 CP를 보존한다.
- 상위 7팀 직행, LCQ 우승 1팀, 8팀 시즌 파이널을 실제 진출 흐름으로 연결한다.
- 시즌 종료 시 우승팀, 플레이어 최종 순위, 주요 기록을 커리어 이력에 남긴다.

완료 기준: 동일 시드에서 페이즈→LCQ→파이널 진출 결과가 재현되고, 진출 자격과 순위 동률 처리 테스트를 통과한다.

구현 메모: 48팀 필드, 3개 페이즈 누적 CP, 승수·팀명 순 동률 처리, 상위 7팀 직행, LCQ 1팀과 8팀 파이널을 엔진·시즌 센터·커리어 이력에 연결했다.

### 2. 패치 메타와 실험체 풀 — 구현됨

- 시즌마다 메타 태그와 강세 역할을 생성하고 경기 전력 계산에 반영한다.
- 선수·팀원별 실험체 풀과 숙련도를 분리한다.
- 마스터즈 3-PICK-BAN과 KEL 2-PICK-CAP의 선택 이력을 대회 전체에서 확인할 수 있게 한다.
- 메타 적응, 숙련도, 조합 시너지의 영향도를 결과 화면에 설명한다.

완료 기준: 금지된 실험체를 선택하지 않고, KEL에서 동일 실험체가 세 번째 선택되지 않으며, 메타 보정의 근거가 UI에 표시된다.

구현 메모: 시즌별 강세 역할 메타, 선수별 3개 실험체 풀과 개별 숙련도, 밴·픽 제한에 따른 대체 픽, 메타·숙련도·로스터 보정값을 엔진에 반영했다. 주간 행동 화면에서 보정 근거를 확인하고 보조 실험체를 교체하거나 개별 숙련도를 훈련할 수 있다.

### 3. 팀 운영과 이적 시장 — 구현됨

- 스카우트 제안, 계약 기간·연봉, 재계약·이적 선택을 추가한다.
- 주전/후보 교체와 선수별 피로·폼·성장을 시즌 운영에 연결한다.
- 팀워크와 역할 시너지가 합동 훈련 및 로스터 변경에 따라 변하도록 한다.
- 계약 만료와 무소속 상태에서도 커리어가 막히지 않는 복귀 경로를 제공한다.

완료 기준: 입단→시즌 진행→재계약 또는 이적의 한 사이클을 완료할 수 있고, 저장 후 계약·로스터 상태가 유지된다.

구현 메모: 팀별 계약 기간·시즌 급여, 계약 만료와 자유계약 전환, 명성·대회 경력 기반 스카우트 제안, 재계약과 이적 선택을 구현했다. 주전·후보 교체는 실제 대회 전력에 반영되며, 교체 직후 팀워크 손실과 합동 훈련에 따른 주전 폼 회복도 적용된다.

### 4. 기록·수상·은퇴 — 구현됨

- 대회 MVP, 시즌 베스트, 통산 우승·순위·대표 실험체 기록을 집계한다.
- 커리어 카드에 팀 이력, 트로피, 대표 실험체와 주요 기록을 포함한다.
- 은퇴 선택과 명예의 전당 심사를 분리하고, 헌액 실패 사유를 명확히 보여 준다.
- 은퇴한 커리어는 읽기 전용 기록으로 보존한다.

완료 기준: 신규 커리어부터 은퇴까지 진행한 뒤 기록 합계가 대회 이력과 일치하고, 커리어 카드 내보내기가 동작한다.

구현 메모: 대회 이력에서 통산 출전·우승·포디움·최고 순위를 집계하고, 마스터즈 시즌 베스트와 대회 MVP를 수상 기록으로 보존한다. 은퇴 후에는 읽기 전용 기록 보관소로 전환되며 별도의 명예의 전당 심사와 확장된 커리어 카드 내보내기를 제공한다.

### 5. 안정화와 밸런스 — 구현됨

- 저장 데이터 마이그레이션과 손상 저장 복구를 버전별로 테스트한다.
- 고정 난수 시드 기반 장기 시뮬레이션으로 티어·명성·우승 분포를 점검한다.
- 모바일 화면, 키보드 조작, 핵심 상태의 접근성 레이블을 검증한다.
- 공식 규칙을 바꿀 때 출처 문서와 팬게임 밸런스 값을 함께 갱신한다.

완료 기준: 단위·통합 테스트와 배포 빌드가 통과하고, 30시즌 자동 진행에서 중단·비정상 수치·저장 손상이 없다.

구현 메모: 저장 스키마 버전 2와 기존 저장 자동 마이그레이션을 적용하고, 파싱 불가능한 저장은 안전하게 초기화한다. 능력치·재화·주차·실험체 풀·주전 인원의 상태 불변식 검사와 고정 난수 기반 30시즌 회귀 테스트를 추가했으며 모바일 조작 크기와 읽기 전용 은퇴 화면을 함께 검증한다.

## 권장 작업 순서

각 단계는 `데이터 모델 → 순수 엔진 로직 → 테스트 → UI → 문서` 순으로 진행한다. 1단계를 우선 완료한 뒤 2단계를 붙이고, 3·4단계는 확장된 커리어 이력 모델을 공유한다. 5단계 검증은 매 단계에 포함하되 전체 회귀 검증을 마지막에 다시 수행한다.

## 범위 원칙

- 실제 선수와 실제 경기 결과를 생성 데이터와 섞지 않는다.
- 공식 대회 구조와 팬게임용 수치·확률을 문서와 UI에서 구분한다.
- 기존 저장 키 `iron-to-fame-save-v1` 사용자의 진행을 가능한 한 보존한다.
- 새 기능은 엔진 테스트 없이 UI에만 구현하지 않는다.
