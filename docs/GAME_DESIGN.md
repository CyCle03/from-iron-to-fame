# 광물에서 명전까지 — 게임 시스템 설계

세부 대회 규칙은 [ESPORTS_RULES.md](ESPORTS_RULES.md), 구현된 랭크·커리어 수치는 [RANK_AND_CAREER_SYSTEMS.md](RANK_AND_CAREER_SYSTEMS.md), 출처는 [DATA_SOURCES.md](DATA_SOURCES.md)를 기준으로 한다.

## 핵심 루프

한 주에 하나의 계획을 선택하고 결과를 확인한다. 랭크는 RP·크레딧·실전 성장의 중심이며, 훈련은 특정 약점을 보완하고 휴식은 장기 효율을 지킨다. 12주가 한 시즌이고, 1년은 약 3시즌으로 구성된다.

## 성장 설계

- **랭크 경기**: 킬/교전은 피지컬·교전, 상위 생존은 판단·팀워크, RP 결과는 멘탈, 모든 경기는 주력 숙련도를 성장시킨다.
- **훈련**: 성적과 무관하게 원하는 능력치를 안정적으로 올리지만 피로가 더 빠르게 쌓인다.
- **피로와 멘탈**: 피로는 경기력에 직접 감점된다. 멘탈은 연패/휴식/대회 성적에 반응한다.
- **장비**: 커리어 크레딧으로 구매하는 창작 성장 보조 장치다. 실제 이터널 리턴 경제와 구분한다.
- **감소 수익**: 높은 능력치일수록 같은 활동의 성장량이 줄어 한 가지 행동 반복을 막는다.

## 시즌과 경쟁 구조

- 시즌 안에 마스터즈 페이즈 3개를 진행하고 서킷 포인트를 누적한다.
- 상위 7팀 직행 + LCQ 1팀이라는 공식 구조는 시즌 센터에 표시한다.
- KEL은 오프닝 위크, 서킷 1~4, 미드시즌 컵, 내셔널 챔피언십의 7개 일정으로 보여 준다.
- 현재 대회 결과는 게임용 시뮬레이션이며, 실제 선수/기록과 분리한다.

## 구현 상태

48팀 마스터즈 시즌, 패치 메타와 실험체 풀, 계약·이적, 주전 로스터, 통산 기록·수상, 은퇴와 명예의 전당까지의 커리어 경로가 구현됐다. 저장 스키마는 이전 데이터를 자동 보완하며 고정 난수 기반 30시즌 회귀 테스트로 장기 상태를 검증한다.

완료 범위와 검증 기준은 [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md), 코드 책임 경계는 [ARCHITECTURE.md](ARCHITECTURE.md)를 기준으로 한다.
