# 랭크·시즌·커리어 시스템

> 현재 코드의 게임 규칙이다. 출처를 표시한 항목 외 수치와 보상은 팬게임 밸런스다.

## 랭크와 입장료

2026-08-19 공식 고객센터의 1인/3인 사전 구성팀 입장료를 기준으로 한다.

| 티어 | RP 시작 | 입장료 |
|---|---:|---:|
| 아이언 4~1 | 0 / 150 / 300 / 450 | 0 |
| 브론즈 4~1 | 600 / 800 / 1000 / 1200 | 10 / 12 / 14 / 16 |
| 실버 4~1 | 1400 / 1650 / 1900 / 2150 | 18 / 20 / 22 / 24 |
| 골드 4~1 | 2400 / 2700 / 3000 / 3300 | 28 / 30 / 32 / 34 |
| 플래티넘 4~1 | 3600 / 3950 / 4300 / 4650 | 36 / 38 / 40 / 42 |
| 다이아몬드 4~1 | 5000 / 5350 / 5700 / 6050 | 45 / 47 / 49 / 51 |
| 메테오라이트 4~1 | 6400 / 6700 / 7000 / 7300 | 53 / 54 / 55 / 56 |
| 미스릴 | 7600 | 58 |
| 데미갓 | 미스릴 상위 1000위 | 58 |
| 이터니티 | 미스릴 상위 300위 | 58 + 9600 RP부터 250 RP당 2 |

공식 상위 티어는 서버 순위를 사용한다. 게임에는 실시간 서버 랭킹이 없어 데미갓·이터니티 판정과 9600 RP 기준을 단순화한다.

## 시즌 진행과 소프트 리셋

- 한 번의 계획으로 12주가 진행되며 1년은 약 3시즌이다.
- 랭크 행동 한 번은 4경기이며 각 경기 시작 시 현재 RP 입장료를 차감한다.
- 순위·킬·경기 변수를 합친 총점에서 입장료를 뺀 값이 순 RP다.
- 결과로 교전·팀워크·판단·멘탈·피지컬, 주력 숙련도, 명성, 크레딧이 성장한다.
- 공식 게임은 생존·제거·빈사와 매칭 평균 티어 보정을 쓰지만 팬게임은 장기 진행에 맞게 단순화했다.
- 공식 소프트 리셋의 존재는 반영하되 공개된 고정 변환식이 아니므로 `다음 RP = 현재 RP × 0.82`를 사용한다. **0.82는 창작 밸런스 값**이다.
- 새 시즌에는 마스터즈 페이즈, KEL 단계, 지역 컵 횟수가 초기화되고 명성·장비·팀·누적 기록은 유지된다.

## 커리어 조건

| 단계 | 게임 내 조건 |
|---|---|
| 지역 컵 | 브론즈(1200 RP) 이상, 시즌당 2회 |
| 아마추어 팀 | 명성 45, 무소속 |
| 마스터즈 | 골드(2400 RP), 명성 75, 소속 팀, 비 KEL 선수 |
| 개인 KEL 합류 | 명성 180, 누적 CP 400 |
| 팀 전체 KEL 승격 | 아마추어/마스터즈 팀, 명성 240, CP 600 |
| 명예의 전당 | 명성 500, 우승 3회, KEL 경력, 메테오라이트(6400 RP) 이상 |

모든 진입 조건과 보상은 실제 계약·승격 제도가 아닌 팬게임용 수치다.

## 팀·역할·경제

- 팀원은 실험체, 역할, 실력, 폼, 피로, 주전 여부를 가진다.
- 하이퍼캐리 태그는 서포터와 보호형 탱커에게 보너스를 받는다.
- 아르다는 하이퍼캐리가 아니며 탱커+근거리 딜러 조합에서 별도 시너지를 받는다.
- 시그니처 조합과 검증된 2인 조합은 소규모 보너스를 준다.
- 크레딧과 장비는 실제 경기 중 키오스크 경제와 별개의 커리어 성장 시스템이다.

## 저장

진행은 브라우저 `localStorage`의 `iron-to-fame-save-v1`에 자동 저장된다. 같은 브라우저·출처에서는 다시 이어지지만 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 기기에서는 공유되지 않는다.
