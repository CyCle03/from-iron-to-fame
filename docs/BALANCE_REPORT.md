# 장기 커리어 밸런스 관측

> 기준일: 2026-10-23 · 저장 스키마 7

## 재현 방법

```bash
npm run balance:analyze
```

`createSeededRandom(1..20)`으로 각각 아이언에서 시작해 30시즌을 진행한다. 팀 합류와 KEL 진입 조건을 만족하면 자동 수락하고, 솔로·마스터즈 구간은 랭크 중심, KEL은 팀 훈련 중심으로 운영한다. 매 시즌 스타즈·히어로즈를 심사하고 30시즌 뒤 은퇴하여 아너스까지 확인한다.

## 기준 결과

| 지표          |                               결과 |
| ------------- | ---------------------------------: |
| KeG 진출      |                               100% |
| 마스터즈 진출 |                               100% |
| KEL 진출      |                               100% |
| 스타즈 선정   |                                30% |
| 히어로즈 선정 |                               100% |

| 최종 RP       | 평균 6,480 · P10 6,310 · P90 6,647 |
| 최종 인지도   |       평균 100 · P10 100 · P90 100 |

## 해석

- 미스릴 기반 KeG 경로는 모든 시드에서 열려 초·중반 진입이 안정적이다.
- 시즌 중간 대회를 반영해 리셋 전 RP를 한 시즌 인정하자 30시즌 최적 플레이에서는 모든 시드가 한 번 이상 마스터즈에 진출했다.
- CP 누적 수정과 시즌 대회 기준 RP가 결합되면서 KEL 100%, 히어로즈 100%, 아너스 65%로 상위 업적이 과도하게 흔해졌다. 소프트리셋 자격 박탈을 되살리지 않고 KEL 선발·메이저 우승 난도를 별도로 조정해야 한다.
- 인지도는 공식 대회 참가자만 상승하지만, 장기 플레이에서는 상단에 밀집한다. 향후에는 단순 누적보다 최근 시즌 활약이나 비활동 감쇠를 검토할 수 있다.

## 다음 밸런스 실험

수치를 바꾸기 전 별도 브랜치나 테스트 표에서 아래 시나리오를 비교한다.

1. 마스터즈 참가 이력은 유지하되 반복 출전과 KEL 선발에 최근 시즌 성적 조건을 추가한다.
2. KEL 진출 목표 5~20%와 히어로즈 1~10%에 맞춰 CP 외에 시즌 파이널 진출·포디움 같은 성적 조건을 실험한다.
3. 스타즈는 현행 조건을 유지하되 인지도 100 장기 고착을 막는 최근 활약 가중치 또는 시즌 감쇠를 실험한다.

목표 범위는 30시즌 기준 마스터즈 30~50%, KEL 5~20%, 히어로즈 1~10%다. 아너스는 희귀한 최종 목표이므로 0~5%를 허용한다. 공식 규칙이 아닌 팬게임 밸런스 목표다.
