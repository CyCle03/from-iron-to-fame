# 장기 커리어 밸런스 관측

> 기준일: 2026-11-25 · 저장 스키마 7

## 현재 상태

- 분석 스크립트를 최소 100개 고정 시드, 30시즌, 랭크 집중·팀 훈련 집중·균형 운영 3전략으로 확장했다.
- 100시드 × 30시즌 × 3전략 × 3규칙(legacy/난도 +0/난도 +20)을 실행했다. +20 후보는 KEL 결승 우승과 히어로즈 달성을 전 전략에서 0으로 만들어 채택하지 않았다. 아래 새 관측을 따른다.
- 아래 "2026-10-23 기준 결과"는 20개 시드·단일 전략의 과거 관측이다. 새 측정 결과로 대체하거나 재사용하지 않는다.
- KEL 선발 기본 정책을 누적 CP 단독 조건에서 "최근 완료 시즌 톱티어 결승 TOP3" 조건으로 바꿨다. 개인 합류·팀 승격·스카우트 제안/수락이 같은 정책을 쓴다.
- 변경 전 CP-only 기준선은 `KEL_SELECTION_LEGACY`로 보존한다. `--legacy` 또는 `--compare`에서만 측정하며 기본 게임 규칙에는 쓰지 않는다.
- 대회 난도는 같은 KEL 정책에서 상대 전력 보정 한 축만 바꿔 비교했다. +20을 기각하고, +5를 기본 규칙(`TOURNAMENT_DIFFICULTY`)으로 채택했다.
- 명예의 전당 판정은 `career.ts`에서 `CAREER_REQUIREMENTS` 상수를 읽도록 연결했다. 기본 수치는 바꾸지 않았다.

## 2026-11-25 관측

환경: 프로젝트 저장소, Windows x64, Node 24.19.0, npm 11.15.0, 고정 시드 1..100, 시드당 30시즌. 모든 커리어는 아이언·일반 유저·유키로 시작한다. 전략은 아래 정의를 따른다.

랭크·균형 전략의 평생 마스터즈/KEL 진출은 모든 규칙에서 100%였다. 팀 훈련만 반복한 전략은 KeG·마스터즈·KEL에 진출하지 못했다. 같은 훈련만 지속하면 공식 대회 자격 RP에 도달하지 못한다는 관측이며, 플레이어가 다음 시즌 랭크 계획으로 전환할 수 없다는 뜻은 아니다.

첫 측정 시도(옛 CP 400→800 실험)는 300초에 타임아웃되어 완료된 수치가 없었다. 위 896초 측정과 혼동하지 않는다. 난도 +20은 재도전 자체는 열려 있어도 우승 경로를 지나치게 닫으므로 기각했다.

### 채택한 +5 조정

명령: `npm run balance:analyze -- --seeds 100 --seasons 30 --strategy all --candidate --quiet`. 같은 환경·시드·초기 조건에서 종료 코드 0, 약 297초. +5는 KEL 진입과 재도전을 유지하면서 우승 비율을 낮췄고, 히어로즈·아너스 달성도 0이 아니므로 기본값으로 채택했다. 과거 평생 희소성 목표 달성을 의미하지 않는다.

한계: 시드 범위·시작 실험체·배경·30시즌 운영 정책에 한정한 관측이다. 무한 시즌, 다른 초기 조건, 수동 로스터/장비 최적화까지 검증한 결과가 아니다. 명전 희소성이 충분한지에 대한 장기 체감 평가는 별도이며, 이번 결정은 사용자가 선택한 재도전 보존 원칙과 같은 조건의 경쟁 결과 개선에 근거한다.

## 재현 방법

```bash
# 기본: 채택한 +5 규칙(candidate), 100시드 × 30시즌 × 3전략
npm run balance:analyze

# 채택한 규칙만 측정 (실험 당시 CLI 이름 candidate 유지)
npm run balance:analyze -- --candidate

# 변경 전 CP-only 기준선만 측정
npm run balance:analyze -- --legacy

# legacy·baseline·candidate를 같은 시드 범위에서 비교
npm run balance:analyze -- --compare

# 빠른 스모크 (밸런스 결론에는 사용하지 않음)
npm run balance:analyze -- --seeds 5 --seasons 3 --strategy rank
```

옵션:

- `--seeds <n>`: 고정 시드 개수. 기본 100. 100 미만이면 경고를 출력한다.
- `--seed-start <n>`: 시작 시드. 기본 1.
- `--seasons <n>`: 시즌 수. 기본 30.
- `--strategy <rank|team|balanced|all>`: 측정 전략. 기본 all.
- `--legacy`: 변경 전 CP-only KEL 기준선만 측정한다.
- `--baseline`: 조정 전 난도 +0 기준선을 측정한다.
- `--candidate`: 채택한 난도 +5를 측정한다(기본값). KEL 정책은 baseline과 같다.
- `--compare`: legacy·baseline·candidate를 같은 시드 범위로 측정해 나란히 비교한다.
- `--quiet`: 시드 진행 로그를 끈다.
- `--help`: 옵션 도움말을 출력한다.

전략 정의:

- `rank`: 매 시즌 랭크 집중 계획을 사용한다.
- `team`: 매 시즌 팀 훈련 집중 계획을 사용한다.
- `balanced`: KEL 구간은 팀 훈련 집중, 그 외 구간은 랭크 집중으로 전환한다.

각 시드는 `createSeededRandom(seed)`에서 새로 시작한다. baseline과 후보는 같은 시드에서 출발하지만 KEL 진입 시점이 달라지면 이후 난수 소비 순서도 달라질 수 있으므로, 개별 경로 동치가 아니라 같은 시드 범위의 분포를 비교한다.

## 목표 범위와 이번 선택

과거 30시즌 평생 달성률 목표는 마스터즈 30~50%, KEL 5~20%, 히어로즈 1~10%, 아너스 0~5%였다. 공식 규칙이 아닌 팬게임 목표이며, 아래 측정 출력의 목표 내/밖 표시는 이 과거 범위와의 비교다.

이번 사용자는 **성장·재도전을 유지하고 시즌별 진출·우승률과 평생 달성률을 분리하는 방향**을 선택했다. 과거 평생 희소성 목표를 강제로 맞추기 위해 성장이나 재도전 횟수를 제한하지 않는다. 이번 조정의 판단 기준은 같은 시드의 시즌별 경쟁 결과가 덜 포화되는지, 세 운영 전략 모두 다음 시즌에 재도전 가능한지다.

## 측정 지표

- 평생 진출·선정률: KeG 진출, 마스터즈 진출, KEL 진출, 스타즈 선정, 히어로즈 선정, 아너스 헌액. 한 번이라도 달성한 시드 비율이다.
- 시즌별 참가·우승률: 전체 시즌 중 마스터즈 참가, KEL 참가, 상위 결승 진출, 시즌 파이널 우승, KEL 결승 우승이 발생한 비율이다. 평생 달성률과 분리해 출력한다.
- 분포: 최종 RP, 최종 인지도, 최종 능력치 평균, 메이저 우승, 전체 우승, 포디움, MVP, KEL 첫 진출 시즌, 마스터즈·KEL 참가 시즌 수, 결승 우승 횟수의 평균·P10·P50·P90.
- 메이저 우승은 마스터즈 시즌 파이널 우승과 KEL 마지막 일정 우승만 센다. 전체 우승과 포디움은 통산 대회 기록 기준이다.
- KEL 첫 진출 시즌은 KEL 기록이 처음 생긴 시즌이다. 진출자가 없으면 `진출 없음`으로 표시한다.
- 전략×후보 조합의 100시드가 끝나면 요약 체크포인트를, 전략의 모든 후보가 끝나면 전체 표를 즉시 출력한다. 타임아웃으로 중단되어도 완료된 체크포인트와 전략 표는 남는다. `--quiet`는 시드 진행 로그만 끄고 완료 출력은 유지한다.

## 개인 KEL 합류 기본 정책

- 조건: 최근 완료 시즌의 `시즌 파이널` 또는 KEL 결승(stage 7)에서 TOP3, 인지도 50, 누적 마스터즈 CP 400.
- `CAREER_REQUIREMENTS.kelRecentFinalPlace`가 3이다. `recentTopTierFinalPlace(game)`가 직전 시즌 결승 기록의 최소 순위를 찾고, `canJoinKel`이 그 순위가 기준 이하인지 확인한다.
- 현재 KEL 소속 선수는 재선발 대상이 아니다. 기존 KEL 계약은 유지되고, 계약이 끝난 뒤 직전 KEL 결승 TOP3를 남겼다면 재선발될 수 있다.
- 개인 KEL 합류(`joinKel`), 팀 전체 KEL 승격(`promoteTeamToKel`), KEL 스카우트 제안 생성·수락(`createScoutOffers`/`acceptScoutOffer`)이 모두 같은 최근 결승 조건을 통과해야 한다. 기존 저장의 KEL 제안도 수락 시 다시 검증한다.
- 팀 전체 KEL 승격의 인지도·CP 기준은 인지도 60·CP 600으로 유지하되, 최근 결승 조건은 개인 합류와 동일하게 적용한다.
- UI 문구는 `kelSelectionRequirementLabel`과 `kelTeamPromotionRequirementLabel`을 사용한다.
- 100시드·3전략에서 최근 결승 조건 추가 전후의 비율은 같았다. 현재 정책은 단위·통합 검사도 통과했다. 다른 시드·시작 배경의 분포까지 같다는 뜻은 아니다.

## 명예의 전당 규칙 상수

- `career.ts`의 스타즈·히어로즈·아너스 판정은 이제 `CAREER_REQUIREMENTS`를 읽는다. 값은 기존과 같다: 스타즈 인지도 70, 히어로즈 메이저 우승 3, 아너스 인지도 90·메이저 우승 5·MVP 2·최상위 무대 5시즌.
- 실제 명전 난도 조정은 측정 후 `CAREER_REQUIREMENTS` 값만 바꾼다. UI 문구도 같은 상수를 읽도록 맞춘다.

## KEL legacy 기준선

- `KEL_SELECTION_LEGACY`는 2026-10-23 이전의 인지도 50·누적 CP 400 조건을 재현한다. `kelRecentFinalPlace`가 `null`이라 최근 결승 성적을 요구하지 않는다.
- 기본 규칙과 후보에는 쓰지 않고 `--legacy`/`--compare` 측정에서만 사용한다. 기존 400 기준선과 새 정책을 같은 시드로 비교하기 위한 장치다.

## 대회 난도 조정

- 실험 기준선은 `TOURNAMENT_DIFFICULTY_BASELINE`(상대 전력 +0), 채택한 기본 난도는 `TOURNAMENT_DIFFICULTY`(상대 전력 +5)다. 이전 +20은 기각했다.
- `simulateTournament`와 `advanceCareerSeason`의 선택적 난도 인자로 주입한다. 높을수록 같은 전력에서 순위가 나빠진다.
- baseline과 candidate는 같은 시드, 같은 KEL 최근 결승 정책, 같은 성장·명전 조건을 쓰고 대회 난도 한 축만 다르다.
- 첫 +20은 KEL 우승 경로를 지나치게 닫았고, +5는 동일 조건의 KEL 우승 빈도를 낮추면서 진출·선정 경로를 유지했다. 기본 런타임과 시즌 유스케이스 모두 +5를 사용한다.

## 성장·재도전 원칙

- 최근 시즌 성적이 기준에 못 미쳐도 다음 시즌 다시 도전할 수 있다. 기존 성장·계약·은퇴 경로를 막지 않는다.
- lifetime KEL 5~20%를 강제하지 않는다. 시즌별 참가·우승률과 평생 달성률을 분리해 기록하고, 목표 판정은 두 축을 함께 본다.

## 마스터즈 목표와 성장 구조

마스터즈는 KEL과 명전의 전제 경로다. 30시즌 중 한 번이라도 진출하는 비율을 낮게 강제하면 후속 경로도 함께 닫힐 수 있다. 사용자 선택에 따라 평생 달성률은 관측 지표로 보존하고, 시즌별 참가·우승률을 별도로 비교한다. 이 결정은 기존 목표의 달성을 주장하는 것이 아니라 평가 계약의 명시적 변경이다.

## 해석

- 2026-10-23 관측에서는 미스릴 기반 KeG 경로가 모든 시드에서 열려 초·중반 진입이 안정적이었다.
- 시즌 중간 대회를 반영해 리셋 전 RP를 한 시즌 인정하자 30시즌 최적 플레이에서는 모든 시드가 한 번 이상 마스터즈에 진출했다.
- CP 누적 수정과 시즌 대회 기준 RP가 결합하면서 KEL 100%, 히어로즈 100%, 아너스 65%로 상위 업적이 과도하게 흔해졌다. 소프트리셋 자격 박탈을 되살리지 않고 KEL 선발·메이저 우승 난도를 별도로 조정해야 한다.
- 인지도는 공식 대회 참가자만 상승하지만, 장기 플레이에서는 상단에 밀집한다. 향후에는 단순 누적보다 최근 시즌 활약이나 비활동 감쇠를 검토할 수 있다.

## 밸런스 조정 원칙

- 단일 성공 사례가 아니라 최소 100개 고정 시드를 아이언부터 30시즌까지 실행해 분포를 비교한다. 기본 전략뿐 아니라 랭크 집중, 팀 훈련 집중, 균형 운영을 분리해 특정 선택만 압도적으로 유리한지 확인한다.
- 각 실험은 마스터즈·KEL 진출률, 우승·포디움·MVP 빈도, 스타즈·히어로즈·아너스 달성률, 최종 RP·인지도·능력치의 평균과 P10·P50·P90을 기록한다.
- 참가 컷, 성장량, 대회 확률, 인지도 보상은 한 번에 한 축만 바꾸고 변경 전후를 같은 시드로 비교한다. 목표 범위를 벗어나면 코드 반영 전에 다시 조정한다.
- 후보를 기본 규칙으로 승격하려면 `--compare` 결과를 먼저 확인하고, 대표 시드를 회귀 테스트에 고정한 뒤 이 문서의 기준 결과와 실행일을 갱신한다. 상태 불변식 통과만으로 밸런스 완료로 간주하지 않는다.

## 다음 밸런스 실험

수치를 바꾸기 전 별도 브랜치나 테스트 표에서 아래 시나리오를 비교한다.

1. +5를 기본값으로 채택했다. 다음 조정 시에도 같은 시드의 시즌별 KEL 참가·우승률과 상위 결승 진출률을 먼저 비교한다.
2. 후보가 부족하면 같은 대회 난도 축의 값만 조정한다. 재도전을 제한하는 연간 선발 쿼터는 도입하지 않는다.
3. 최근 시즌 성적 조건은 유지하되, 재도전을 막지 않는 범위에서 결승 진출·포디움 가중치를 정교화한다.
4. 스타즈는 현행 조건을 유지하되 인지도 100 장기 고착을 막는 최근 활약 가중치 또는 시즌 감쇠를 실험한다.
5. 명전 조건 자체는 유지하고 대회 난도 조정에 따른 달성 분포를 먼저 관측한다. 과거 평생 희소성 목표를 강제하기 위해 명전 조건을 올리지 않는다.
