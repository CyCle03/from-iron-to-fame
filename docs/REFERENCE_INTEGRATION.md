# 레퍼런스 분석 반영 기록

기준 문서: `bench-to-ballon-reference.md` (2026-10-23 제공본)

## 이번 반영

- 시즌 단위 진행은 유지하되, 시즌 완료 뒤 한 번의 **전환점 선택**을 제공한다.
- 전환점은 이터널 리턴 맥락으로 재구성했다: 밴픽 대응용 보조 실험체 숙련도, 3인 스쿼드 교전 콜, 안전 구역·교전 로그 분석.
- 선택지는 하나만 확정할 수 있고, 보상과 손실 없는 최적해가 되지 않도록 서로 다른 성장 축에 보상을 배분한다.
- 홈의 다음 커리어 목표와 시즌 결산을 이어, 다음 시즌 전에 할 일을 한 장으로 확인하게 한다.

## 의도적으로 제외한 것

- 축구 학교/구단/국가대표/병역 구조와 원작의 화면·문구·시각 자산은 사용하지 않는다.
- 주간 행동력 반복 입력은 이전 설계 결정에 따라 도입하지 않는다. 이 게임은 12주를 한 시즌으로 자동 진행하며, 회복 일정도 엔진이 자동 조절한다.
- 실제 선수·팀·커뮤니티 계정 서사는 사용하지 않는다.

## 다음 확장 후보

- 구현 완료: 시즌 결산과 최근 20경기에 평균 순위·평균 TK·승률·TOP 3·총 RP를 큰 수치로 표시
- 명예의 전당 리포트에 티어 이력, 팀 이력, 결정적 전환점 3개를 포함
- KEL/마스터즈 결승에 구역 전환·교전·탈락·우승을 재생하는 짧은 하이라이트 타임라인
