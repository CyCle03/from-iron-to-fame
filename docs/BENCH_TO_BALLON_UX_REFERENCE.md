# 벤치에서 발롱까지 UI/UX 레퍼런스

> 조사일: 2026-10-23 KST  
> 대상: [벤치에서 발롱까지](https://kickru.com/)  
> 목적: 광물에서 명전까지의 정보 밀도, 생성 흐름, 시즌 진행과 결과 연출을 개선하기 위한 UX 레퍼런스다. 축구 시스템·표현을 복제하지 않고, 구조와 상호작용 원칙만 참조한다.

## 조사 범위와 한계

- 공개 홈페이지와 [공식 게임 가이드](https://kickru.com/guide)를 확인했다.
- 사용자가 제공한 실제 플레이 분석 문서와 53장의 연속 캡처로 유스부터 40세 자동 은퇴·기록 보관소까지의 화면 흐름을 추가 검토했다.
- 캡처에서 관찰한 구조와 본 게임의 적용 수치는 구분한다. 원작의 명칭·이미지·문구·실존 팀 표현은 복제하지 않는다.

## 참조할 시각·상호작용 원칙

### 1. 한 화면에 한 결정만 둔다

생성 과정은 “모든 입력을 한 폼에 채우기”가 아니라, 정체성 → 역할/포지션 → 플레이 스타일 → 성장 중점 → 확인 순으로 나눌 때 부담이 적다. 현재 게임의 단계형 생성은 이 방향을 유지하고, 각 단계에서 선택 결과가 다음 화면의 한 줄 요약으로 이어져야 한다.

**광물에서 명전까지 적용**

- 닉네임/배경, 역할군, 플레이 스타일, 집중 능력치 2개, 주력 실험체 배정의 다섯 단계를 유지한다.
- 각 단계 상단에는 현재 선택을 1줄 칩으로 표시하고, 마지막 확인 화면에는 선택한 역할군과 무작위 배정된 실험체를 크게 보여 준다.
- 무작위 실험체는 “다시 굴리기”가 아니라 “이 역할군에서 발견한 주력 후보”처럼 커리어 서사로 표현한다.

### 2. 시즌은 버튼 한 번, 결과는 시간 순서로

공식 가이드의 시즌 단위 진행은 반복적인 주간 입력을 줄이는 방식이다. 우리 게임도 12주 자동 운영을 유지하되, 결과를 한 장의 숫자 묶음으로 끝내지 않아야 한다.

**광물에서 명전까지 적용**

- 시즌 종료 때 개별 경기를 길게 재생하지 않고 게임 수·평균 순위·평균 TK·승률·TOP 3·총 RP를 먼저 보여 준다.
- 최근 20경기 순위 스트립과 시즌 집계를 분리하고, 마지막 티어 변동과 소프트 리셋도 별도로 보여 준다.
- 결산은 긴 경기 재생 없이 3장의 짧은 브리핑으로 읽고 다음 시즌 준비로 이동한다.
- 지역 컵·마스터즈·KEL이 있었던 시즌은 랭크 행과 섞지 않고, 마지막에 대회 하이라이트 카드로 별도 연출한다.

### 3. 첫 화면의 정보는 행동에 필요한 것만

레퍼런스는 여섯 핵심 능력치와 오버롤 같은 바로 비교 가능한 정보로 시작한다. 우리 게임은 능력치가 8개이고 랭크·인지도·크레딧·팀 상태까지 존재하므로, 첫 화면에 모두 동등하게 놓으면 모바일에서 읽기 어려워진다.

**광물에서 명전까지 적용**

- 상단 고정 정보는 티어/RP, 다음 승급, 입장료, 인지도으로 제한한다. 컨디션 수치는 제거하고 시즌 결산의 운영 상태로만 제공한다.
- 피지컬·교전·운영·판단을 주요 능력치로 먼저 보여 주고, 팀워크·멘탈·집중력·적응력은 상세 보기로 접는다.
- 장비, 로스터 상세, 조합 보너스, 대회 규칙은 해당 탭에서만 강조한다.
- 숫자만 나열하지 말고 다음 목표와 직접 연결한다. 예: 골드까지 83 RP, 마스터즈 조건: 인지도 15 중 8.

### 4. 장기 커리어는 이정표로 읽힌다

레퍼런스의 데뷔→주전→국가대표→발롱도르 흐름처럼, 현재 위치와 바로 다음 단계가 동시에 보여야 한다.

광물에서 명전까지의 경로는 다음과 같다.

랭크 입문 → 지역 컵 → 아마추어 팀 → 마스터즈 → KEL → 명예의 전당

- 전체 여정을 항상 작게 표시하되, 사용자가 당장 할 수 있는 목표는 하나만 강조한다.
- 명예의 전당 요구 조건을 초반부터 전부 크게 노출하지 않고 KEL 진입 뒤에 상세화한다.
- 시즌 결산 뒤에는 이번 시즌으로 열린 다음 기회를 한 장만 제안한다.

### 5. 모바일은 좁은 화면이 아니라 우선순위가 다른 화면이다

레퍼런스가 모바일 브라우저 기반으로 설계된 것처럼, 모바일에서는 데스크톱 패널을 축소하지 않는다.

**광물에서 명전까지 적용**

- 결산은 하단 시트, 생성은 한 열 카드, 탭은 가로 스크롤로 사용한다.
- 최소 터치 영역은 44px, 주요 CTA는 화면 폭을 충분히 사용한다.
- 테이블은 핵심 열만 남기고, 상세 정보는 행을 눌러 펼친다.
- 시즌 결산에서는 입장료를 숨길 수 있지만 순위·킬·RP는 항상 한 줄에 보인다.

## 구현 우선순위

1. 결산 마지막 장의 공식 대회 기록을 승부처 하이라이트 카드로 확장
2. 대시보드의 상단 HUD를 핵심 3지표 중심으로 축소
3. 생성 마지막 확인 화면에 커리어 프로필 카드 추가
4. 다음 목표의 남은 조건을 수치 게이지로 표시
5. 저장 파일 내보내기/가져오기 동선을 설정 메뉴에 더 명확히 노출
6. Computer Use 가능한 환경에서 신규 생성→시즌 3회→은퇴 흐름을 실제 조작해 이 문서의 관찰 항목을 보강

## 연속 플레이 캡처에서 추가로 확인한 흐름

제공된 53장에서는 시즌 결과가 단독 통계 화면으로 끝나지 않고 `결산 → 전환점 → 계약/소집 → 반응 → 다음 시즌`으로 이어졌다. 후기에는 능력치 하락과 우승이 동시에 발생하고, 은퇴 권고를 거절하면 마지막 계약을 탐색하며, 제안이 없을 때 커리어 아카이브로 전환됐다.

이터널 리턴 팬게임에는 다음 원칙만 변환해 적용한다.

- 시즌 결산은 `핵심 티어 변화`, `DAK.GG형 평균 지표`, `새로 열린 할 일`의 3장 브리핑으로 표시한다.
- 전환점과 팀 제안은 결산 마지막 장의 확인할 일로 연결하되, 실제 선택은 각각의 전용 카드에서 한다.
- 계약 제안은 팀명보다 예상 역할, 경쟁 무대, 팀 적합도, 기간과 보상을 같은 순서로 비교한다.
- 후기 커리어는 단순 능력치 감소가 아니라 샷콜·멘토링·넓은 실험체 폭으로 보완하는 역할 전환으로 설계한다.
- 은퇴 권고와 자동 종료는 현재 미구현이다. 향후 최근 시즌 성과 하락, 주전 비율, 계약 제안 유무를 근거로 별도 단계에서 구현한다.

### 이번 반영 범위

- 시즌 종료 모달을 3단계 브리핑으로 개편했다.
- 마지막 장에서 성장 전환점, 스카우트 제안, 공식 대회 기록의 개수를 보여 준다.
- 스카우트 제안 카드에 예상 역할·진출 경로·팀 적합도를 추가했다.
- 모바일에서는 결산 한 장이 화면 대부분을 사용하고, CTA를 하단에 유지한다.
